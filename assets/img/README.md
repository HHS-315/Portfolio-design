# 이미지 폴더 (assets/img)

사이트에서 쓰는 이미지(일러스트, 사진 등)를 여기에 넣습니다.

## GitHub 웹에서 업로드하는 법
1. https://github.com/HHS-315/Portfolio-design 접속
2. 브랜치를 `claude/git-sync-main-9ab8dc` 로 변경
3. 이 폴더(`assets/img`)로 이동 → `Add file` → `Upload files`
4. 이미지를 끌어다 놓고 (예: `hero.png`) `Commit changes`

업로드한 파일은 `./assets/img/<파일명>` 경로로 참조합니다.
예: `<img src="./assets/img/hero.png" alt="..." />`
